# Benchmarks

Use this folder to compare AI coding tools on your real workflow.

Do not benchmark only vibes.

Run the same task across tools and record:

- Tool
- Model
- Task type
- Context size
- Agent mode
- Cost estimate
- Time saved
- Output accepted
- Review effort
- Notes

Start with: [benchmark-template.csv](benchmark-template.csv)

## Suggested benchmark tasks

1. Explain a bug in a small function.
2. Generate unit tests for one file.
3. Refactor a two-file module.
4. Implement a small feature from an issue.
5. Review a pull request.
6. Debug a failing CI test.
7. Update documentation from code changes.
8. Create an implementation plan for a migration.

## Key takeaway

The best tool is the one that gives your team the best cost-quality-review balance.
